## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - 最初の設定のモデル（gemini-3.5-flash-lite）のまま、`uv run python -m app.ask "LoRAとは何ですか？"` を3回実行して、毎回同じ答えが返ってくるのか試してみた。
  - `AIE_MODEL=gemini-3.5-flash` をつけてモデルを切り替え、同じ質問を2回実行して、モデルによって答え方がどう変わるのか比べてみた。
- 結果：
  - 同一モデルでの複数回実行（gemini-3.5-flash-lite × 3回）：
    3回とも核心部分（元モデルを固定し差分のみ学習、低コスト・小容量）は一貫していたが、実行ごとに見出しの構成、例え話の表現（「付箋」と「小さなメモ帳」）、読み仮名（「ローラ」と「ロラ」）などが変化した。また1回目には「生成AIブロード」という不自然な表現も見られた。
  - モデル変更による比較（gemini-3.5-flash × 2回）：
    gemini-3.5-flash では、基本説明に加えて「低ランク行列分解（Low-Rank Matrix Decomposition）」という数学的手法への言及（1回目）や、「2021年にMicrosoftの研究者らによって提案された」という背景情報（2回目）など、より専門的で詳細な内容が含まれるようになった。
- 気づき・疑問：
  - 同じモデル・同じ質問でも、AIに聞くたびに毎回少しずつ違う文章が返ってくるのが面白いなと思った。
  - 軽いモデル（flash-lite）でもざっくり意味を知るには十分だが、たまに変な日本語が混ざることがあった。しっかりした詳しい説明が欲しいときは上位のモデル（flash）の方が良さそうで、目的によってモデルを使い分けるのが大事なんだと気づいた。
  - もし毎回ブレずに同じ形で答えてほしいときは、どうやって指示を出せばいいのか気になった。
